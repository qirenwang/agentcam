We are building AgentCam V1.

Project title:
AgentCam: Agentic Perception Routing for Camera-Degraded Autonomous Driving

Current dataset:
- Google Drive file ID: 1ROUN1MkJ2l36KLBsEf_-BNF81xFD2uWe
- Expected archive name: data_eda_most25.zip
- The dataset was previously organized for YOLOv8 fine-tuning from COCO-pretrained weights.
- Assume YOLO-format annotations.
- Assume only train and test splits currently exist.
- Assume only two camera degradation types: overexposure and blur.
- Do NOT assume clean/normal data unless discovered by the data audit.
- Some images may be unlabeled. Missing label files and empty label files must be distinguished.

Core research scope:
Implement a reproducible V1 experimental pipeline for camera-degraded dashcam object detection.
The key contribution is a rule-based agentic perception router, not a learned router, not VLM/LLM reasoning, and not heavy image restoration.

V1 architecture:
1. YOLOv8 fast detector always runs.
2. A degradation monitor computes blur_score and overexposure_score.
3. An uncertainty monitor extracts YOLO confidence statistics.
4. A rule-based router selects one action:
   - YOLO_ONLY
   - EXPOSURE_ENHANCE_THEN_YOLO
   - SHARPEN_THEN_YOLO
   - RTDETR_VERIFY
   - UNCERTAINTY_SIGNAL
   - TEMPORAL_RECOVERY only if sequence metadata exists; disabled by default.
5. The system logs selected action, degradation scores, detector confidence, predictions, and latency.
6. RTX PRO 6000 is the development and offline evaluation platform.
7. Jetson AGX Orin deployment is a later validation stage after the V1 pipeline works.

Critical split policy:
The archive has train/test only. Do not tune on test.
Create these processed splits:
- train_core: sampled from original train, used for fine-tuning.
- val_from_train: sampled from original train, used for checkpoint selection and router threshold calibration.
- test: original test, untouched, final reporting only.

Use stratified sampling by degradation type when splitting original train.
If sequence_id can be inferred, split by sequence to avoid leakage. If sequence_id cannot be inferred, use image-level stratified split and report this limitation.

Critical label policy:
- If label .txt exists and is empty, treat as a labeled negative frame.
- If label .txt is missing, treat as unlabeled.
- Unlabeled frames can be used for degradation-score statistics and latency measurements.
- Unlabeled frames must not be used for mAP evaluation or supervised training.
- Do not silently treat missing label files as empty labels.

T08. Rule-based agentic router
Implement:
agentcam/routing/rule_router.py
agentcam/routing/run_router.py

Router inputs:
- blur_score;
- overexposure_score;
- saturated_pixel_ratio;
- YOLO mean confidence;
- YOLO max confidence;
- number of YOLO detections;
- low-confidence detection ratio;
- optional temporal consistency, only if sequence metadata exists;
- latency_budget_ms.

Actions:
YOLO_ONLY
EXPOSURE_ENHANCE_THEN_YOLO
SHARPEN_THEN_YOLO
RTDETR_VERIFY
UNCERTAINTY_SIGNAL
TEMPORAL_RECOVERY disabled by default.

Thresholds:
Configured in configs/router_rule.yaml.
Support quantile-based thresholds calibrated on val_from_train only.
Do not tune thresholds on test.

CLI:
python -m agentcam.routing.run_router \
  --data data/processed/agentcam \
  --scores artifacts/scores/degradation_scores.csv \
  --yolo_weights artifacts/runs/yolov8_agentcam/weights/best.pt \
  --rtdetr_weights weights/rtdetr_agentcam.pt \
  --config configs/router_rule.yaml \
  --split test \
  --out artifacts/predictions/agentcam_router_test.json \
  --log artifacts/logs/router_test.jsonl

T09. Fusion logic
Implement agentcam/routing/fusion.py.
V1 fusion:
- start with YOLO detections;
- if enhanced YOLO is called, replace boxes only when class matches, IoU > 0.5, and enhanced score is higher;
- if RT-DETR is called, merge YOLO and RT-DETR detections using class-aware NMS;
- keep source tags;
- log frame-level uncertainty_signal.

T11. Offline oracle analysis
Implement agentcam/routing/oracle.py.
For each labeled test frame, compare candidate actions:
YOLO_ONLY, RTDETR_ONLY, EXPOSURE_ENHANCE_THEN_YOLO, SHARPEN_THEN_YOLO, YOLO_PLUS_RTDETR_ALWAYS.
Compute an upper-bound action choice using:
utility = detection_metric_gain - lambda_latency * latency_ms - beta_critical_miss * critical_miss

This is analysis only. Do not use test labels to tune the deployed rule-based router.
